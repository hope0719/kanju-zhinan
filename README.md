# 看剧指南 · AI 短剧分析官

> **一句话定位**：用 AI 帮你回答两个问题 ——
> 1. **「到底什么短剧好看？」**（荐剧）
> 2. **「这部剧好不好看 / 讲的是什么？」**（查剧避雷）
>
> 仓库英文名：`kanju-zhinan` ｜ 适用平台：红果 / 番茄 / 抖音短剧

---

## 一、这个项目是什么

短剧数量爆炸，标题党、流水线套路、付费拉扯泛滥。观众常被「前 3 集免费」骗进去，
结果 90 集注水 + 烂尾 + 充值解锁。

本项目的核心方法论来自抖音博主 **ebanofear** 的视频
《睡前分享之红果使用教程 · 睡前求来的看剧指南》（红果短剧使用教程，全是干货）。
博主在视频里用一套 **「剧名判断法」** 手把手教大家避雷。我们把这套人肉经验
**升级为「剧名初判 + AI 联网核验 + 八维评分」**，让 AI 比你盲猜更稳地判定一部短剧值不值得看。

### 方法论基石：剧名判断法（来自视频原话，已结构化）

- ❌ **标题直接剧透 / 套路化的，别看**：一眼能猜出 100 集剧情的基本是流水线
  （重生后悔流、打脸逆袭流、追妻火葬场、系统空间流）。
- ✅ **标题看不出剧情、有悬念的，可以看**：例如《将门六叔》《后妈只小狗老公非要凑》。
- 🚩 **识别套路标签**：重生 / 系统 / 空间 / 豪门 / 追妻 / 打脸 / 逆袭 / 神豪 / 战神 / 闪婚 / 虐恋。
- 🛑 **博主点名避雷**：《甜宝来了》《水里面有怪兽不要去》《牙牙穿越世界古代穿到现代》等。
- 👍 **博主点名可看**：《将门六叔》《后妈只小狗老公非要凑》《九毒文盲出了个读书人》等。

> 用法：拿到剧名第一步先跑「剧名初判」，再联网核验，避免被标题党骗。

## 二、它解决什么痛点

| 痛点 | 看剧指南怎么做 |
|---|---|
| 标题党骗点击 | 剧名初判 + 联网核验，先看口碑再决定 |
| 流水线套路剧 | 八维评分里「套路与坑」维度专门扣分 |
| 烂尾 / 注水 | 检索网友评价与结局反馈，提前避雷 |
| 付费拉扯 | 性价比维度标注「红果免费 / 需解锁」 |
| 不知道看啥 | 荐剧模式按偏好分级推荐 |

| 模式 | 触发方式 | 产出 |
|---|---|---|
| **A · 查剧** | 「分析一下《XXX》」「这部《XXX》好不好看」 | 明确结论（👍/👌/⚠️/👎）+ 八维评分 + 内容梗概 + 避雷 + 渠道 |

## 四、八维评分体系

| 维度 | 含义 | 高分信号 | 低分信号 |
|---|---|---|---|
| 题材新鲜度 | 套路化程度 | 反套路、设定新颖 | 纯流水线重生/追妻 |
| 开篇钩子 | 前 3 集抓人程度 | 开头即冲突/悬念 | 慢热、铺垫冗长 |
| 爽点密度 | 反转/打脸/逆袭节奏 | 节奏快、爽感足 | 注水、拖沓 |
| 情绪价值 | 解压/共鸣/共情 | 强情绪反馈 | 矫情、无代入感 |
| 制作质感 | 演技/服化道/剪辑/BGM | 在线、不廉价 | 五毛、尬演 |
| 口碑评分 | 红果/番茄/网友评分 | 高分开局、完播率高 | 低分、差评集中 |
| 套路与坑（越低越好） | 烂尾/付费拉扯/标题党 | 完整、不坑钱 | 烂尾、付费卡点 |
| 性价比 | 红果免费 / 付费平台 | 红果免费可看全 | 需解锁、套路付费 |

**结论四档（必须明确给一档）：**
- 👍 **强烈推荐**（综合 ≥ 7.5）：口碑好 + 爽点密 + 少坑，放心冲。
- 👌 **可以看看**（6–7.5）：打发时间还行，有瑕疵但不亏。
- ⚠️ **浅尝辄止**（5–6）：看前 3 集试水，别上头、别充值。
- 👎 **不建议**（< 5）：套路重 / 烂尾 / 注水 / 脑残，别浪费时间。

## 五、怎么用（两种方式）

### 方式 1：作为 WorkBuddy 技能（推荐）

1. 把本仓库的 `SKILL.md` 复制到本地技能目录：
   ```bash
   mkdir -p ~/.workbuddy/skills/kanju-zhinan
   cp SKILL.md ~/.workbuddy/skills/kanju-zhinan/
   ```
2. 在 WorkBuddy 对话里直接说：
   - 「分析一下《将门六叔》好不好看」
   - 「红果上现在什么短剧值得看？推荐几部」
3. AI 会自动联网检索 + 八维评分 + 出报告。

### 方式 2：作为独立提示词（任意 AI）

打开 [`prompts/analyze.md`](prompts/analyze.md)，把里面的提示词 + 你要查的剧名
发给任意支持联网搜索的 AI（ChatGPT / 豆包 / 通义 / Claude）即可，**无需 WorkBuddy**。

## 八、免责声明

- 短剧口碑随时间、版本、平台变动极大，评分仅为 **相对短剧品类的爽感/性价比参考**，
  不是影视艺术评分。
- AI 结论依赖联网检索到的公开信息；冷门剧可能无数据，结论以剧名与同类套路推断，
  已注明「无公开数据」。
- 红果 / 番茄短剧大多免费（看广告解锁），警惕「付费解锁大结局」类套路。
